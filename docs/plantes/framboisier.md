# Framboisier — *Rubus idaeus* (Rosacées)

## 1. Identité
- Autres noms : framboisier commun, ronce des montagnes.
- Parties utilisées : feuilles (tisane) ; fruits (alimentation).
- Origine : 🇫🇷 France (sauvage en lisière, cultivé partout — un des fruits rouges préférés des Français).

## 2. Usages
- Traditionnels : tisane des derniers mois de grossesse (préparation à l'accouchement, usage traditionnel des sages-femmes) ; feuilles « féminines » des campagnes.
- Documentés : usage traditionnel reconnu (EMA, *Rubi idaei folium*) pour les troubles menstruels légers ; l'usage en fin de grossesse : tradition sages-femmes, **à valider avec la professionnelle qui suit la grossesse** (pas d'automédication).

## 3. Préparations
- Infusion : 1–2 g de feuilles séchées / 250 ml — eau 90 °C, couvert, 10 min.
- Décoction douce : feuilles coriaces, frémissement doux ~95 °C 5 min puis couvert 10 min possible.
- 🌡️ Sensibilité : tanins stables ; l'infusion douce suffit, pas besoin de bouillir.

## 4. Posologie
- Adulte (femme) : 1–2 tasses/jour ; tradition sages-femmes : usage progressif sur le dernier trimestre, **uniquement avec suivi professionnel**.
- Hors grossesse : usage ponctuel en cours de cycle.

## 5. Contre-indications
- **Grossesse : uniquement le dernier trimestre, uniquement avec suivi professionnel** (par prudence, pas avant) ; allaitement : prudence (données limitées) ; enfants : non recommandé en usage régulier.

## 6. Interactions
- Prudence théorique avec les traitements utérotoniques et les anticoagulants (données limitées).

## 7. Signaux d'alerte
- Contractions avant terme, tout signe anormal pendant la grossesse → **urgence obstétricale**, pas une tisane.

## 8. Note
Une plante de sages-femmes, transmise oralement de génération en génération — le livre la met entre les mains du lecteur comme une tradition à pratiquer **avec** son professionnel, jamais seul.

## 9. Sources
- EMA, *Rubi idaei folium* (usage traditionnel). — Usage grossesse : tradition sages-femmes, à référencer (#6).
