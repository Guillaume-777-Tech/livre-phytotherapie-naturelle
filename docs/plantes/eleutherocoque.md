# Éleuthérocoque — *Eleutherococcus senticosus* (Araliacées) 🚩

**⚠️ Encadré de sécurité :**
- Prudence : hypertension, palpitations, insomnie.
- Contre-indiqué : grossesse, allaitement, enfants.
- Interactions : anticoagulants, hypoglycémiants, stimulants — avis médical obligatoire si traitement en cours.

## 1. Identité
- Autres noms : ginseng de Sibérie (sans être un ginseng), buisson du diable.
- Parties utilisées : racine.
- Origine : 🌍 Asie de l'Est (Sibérie russe, Chine du Nord-Est) ; peu cultivé en France → herboristerie avec traçabilité.

## 2. Usages
- Traditionnels : adaptogène sibérien (médecine traditionnelle chinoise et russe) ; tonique de l'effort physique et intellectuel.
- Documentés : usage traditionnel reconnu (EMA, *Eleutherococci radix*) pour la fatigue passagère ; adaptogène étudié chez les sportifs soviétiques dès les années 1960.

## 3. Préparations
- Décoction : 1–2 g de racine coupée / 250 ml — frémissement doux ~95 °C, 10–15 min, couvert.
- Teinture : selon herboristerie (forme pratique pour la cure cyclique).
- 🌡️ Sensibilité : éleuthérosides assez stables ; décoction douce classique.

## 4. Posologie
- Adulte : 1 tasse le matin ; cures de 3 semaines, pause 1–2 semaines.
- Grossesse, allaitement, enfants : non recommandé.

## 5. Contre-indications
- Hypertension non contrôlée, insomnie ; maladies auto-immunes : prudence (immunostimulation théorique).

## 6. Interactions
- AVK, hypoglycémiants, digoxine (données limitées) : avis médical indispensable.

## 7. Signaux d'alerte
- Palpitations, tension qui monte, troubles du sommeil → arrêt.

## 8. Note
Le « ginseng du pauvre » selon les Russes : moins cher, moins stimulant, mais le même esprit adaptogène en plus doux.

## 9. Sources
