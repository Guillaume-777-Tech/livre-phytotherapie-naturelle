# Valériane — *Valeriana officinalis* (Caprifoliacées)

## 1. Identité
- Autres noms : herbe aux chats, guérit-tout.
- Parties utilisées : racines et rhizomes séchés.
- Origine : 🇫🇷 France (sauvage, prairies humides et bords de rivières ; cultivée).

## 2. Usages
- Traditionnels : sommeil difficile, nervosité, agitation ; usage remontant à l'Antiquité grecque.
- Documentés : usage traditionnel reconnu (EMA, *Valerianae radix*) pour le sommeil et la nervosité ; nombreuses études cliniques.

## 3. Préparations
- Infusion des racines : 1–2 g / 250 ml — eau frémissante 90 °C, couvert, 10–15 min.
- 🌡️ Sensibilité : les valepotriates et l'acide valérénique sont sensibles à l'ébullition prolongée ; frémissement léger si infusion longue.
- Erreurs courantes : s'attendre à un effet immédiat (effet utile après 1–2 semaines de cure) ; se laisser décourager par l'odeur.

## 4. Posologie
- Adulte : 1 tasse le soir 30–60 min avant le coucher, éventuellement 1 le matin en cas de nervosité.
- Enfant : non recommandé sans avis professionnel.
- Durée : cures de 2–4 semaines.

## 5. Contre-indications
- Grossesse, allaitement, enfants < 12 ans (données insuffisantes) ; maladies du foie (prudence).

## 6. Interactions
- Potentialisation possible des sédatifs (benzodiazépines, somnifères) : avis professionnel obligatoire.

## 7. Signaux d'alerte
- Effet paradoxalement excitant chez certaines personnes → arrêt ; somnolence diurne excessive → réduire la dose.

## 8. Note
L'odeur « de chaussette » est normale — c'est celle des actifs. Attirante pour les chats.

## 9. Sources
- EMA, *Valerianae radix* (usage traditionnel). — À compléter par le relecteur (#6).
