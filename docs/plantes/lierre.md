# Lierre grimpant — *Hedera helix* (Araliacées) 🚩

**⚠️ Encadré de sécurité :**
- **Baies TOXIQUES** (saponines) — jamais de consommation, jamais d'automédication avec les baies.
- Respecter strictement la posologie des préparations de feuilles ; surdosage = irritation digestive, nausées.
- Tisane de feuilles : prudence chez la femme enceinte et les enfants (données limitées) — formes standardisées (syrup de pharmacie) souvent préférables.

## 1. Identité
- Autres noms : herbe de Saint-Jean grimpante, lierre commun.
- Parties utilisées : feuilles (jamais les baies).
- Origine : 🇫🇷 France (sauvage, haies, murs, forêts — partout).

## 2. Usages
- Traditionnels : toux productive, bronchites légères ; le lierre était l'emblème de Dionysos et des toux sacrées d'Esculape.
- Documentés : usage traditionnel reconnu (EMA, *Hederae folium*) comme expectorant pour la toux ; les sirops standardisés de lierre (pharmacie) sont bien documentés chez l'enfant.

## 3. Préparations
- Infusion des feuilles : 0,3–0,5 g (quelques feuilles) / 250 ml — eau frémissante 80–90 °C, couvert, 10 min.
- **Forme recommandée pour la famille** : sirop standardisé de lierre (pharmacie, doses maîtrisées) plutôt que préparation maison incertaine.
- 🌡️ Sensibilité : saponines hédéracines assez stables ; mais garder une extraction douce pour éviter de concentrer les fractions irritantes.
- Erreurs courantes : confondre feuilles et baies ; surdoser « parce que c'est naturel ».

## 4. Posologie
- Adulte : 1–2 tasses de feuilles/jour, cures de 4–5 jours.
- Enfant (> 6 ans) : forme standardisée de préférence, après avis professionnel.
- Durée : 4–5 jours ; si la toux persiste → consultation.

## 5. Contre-indications
- Grossesse, allaitement ; enfants < 6 ans en préparation maison ; baies (toujours).

## 6. Interactions
- Prudence avec les antitussifs et les mucolytiques (effets opposés/additifs selon le type de toux) → avis professionnel.

## 7. Signaux d'alerte
- Toux persistante > 5 jours, fièvre, respiration sifflante → consultation médicale ; tout symptôme après ingestion accidentelle de baies → centre antipoison.

## 8. Note
Pourtant présent partout, le lierre n'est pas comestible : c'est une plante de pharmacie, pas de jardin-cuisine.

## 9. Sources
- EMA, *Hederae folium* (usage traditionnel). — À compléter (#6).
