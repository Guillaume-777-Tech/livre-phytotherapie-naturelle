# Cyprès — *Cupressus sempervirens* (Cupressacées)

## 1. Identité
- Autres noms : cyprès de Provence, cyprès d'Italie.
- Parties utilisées : cônes galbules (jeunes fruits), rameaux.
- Origine : 🇪🇺 Méditerranée orientale ; naturalisé dans tout le Midi 🇫🇷 (haies, alignements).

## 2. Usages
- Traditionnels : préparations hivernales méditerranéennes, soutien circulatoire des jambes ; usage populaire provençal et grec.
- Documentés : usages traditionnels (huile essentielle documentée en aromathérapie encadrée) ; à référencer précisément.

## 3. Préparations
- Décoction de jeunes cônes : 1 c. à café / 250 ml — frémissement doux ~95 °C, 10 min, couvert.
- 🌡️ Sensibilité : parties résineuses assez stables ; frémissement doux pour ne pas concentrer les résines amères.

## 4. Posologie
- Adulte : 1–2 tasses/jour en cure courte hivernale.
- Enfant : usage sur avis professionnel uniquement.
- Durée : 5–10 jours, pauses.

## 5. Contre-indications
- Grossesse, allaitement (données insuffisantes) ; HE : grossesse, allaitement, jeunes enfants (règles HE).

## 6. Interactions
- Prudence avec les traitements circulatoires veineux (effets additifs théoriques).

## 7. Signaux d'alerte
- Symptômes respiratoires ou circulatoires qui persistent → consultation.
