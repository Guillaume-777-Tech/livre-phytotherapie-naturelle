# Camomille matricaire — *Matricaria recutita* (Astéracées)

**Encadré de sécurité** : allergie connue aux Astéracées (ambroisie, armoise…) → contre-indication. Pas de données suffisantes aux doses alimentaires chez la femme enceinte : avis professionnel recommandé en usage régulier.

## 1. Identité
- Autres noms : camomille allemande, matricaire camomille, petite camomille.
- Parties utilisées : fleurs séchées (capitules).
- Habitat et récolte : Europe dont France (cultivée en Pays de la Loire, sauvage dans les champs et friches) ; floraison mai–septembre, récolte des fleurs pleinement ouvertes.

## 2. Usages
- Traditionnels : digestion difficile, ballonnements, sommeil léger, inflammation des muqueuses ; usage millénaire (Égypte, Grèce antique).
- Documentés : l'EMA reconnaît l'usage traditionnel pour les troubles digestifs légers et l'aide au sommeil (monographie *Matricariae flos*).

## 3. Préparations
- Infusion : 1 c. à soupe de fleurs / 250 ml — **eau frémissante 80–90 °C, jamais bouillante**, couvert, 10 min. Filtrer.
- Teinture-mère : selon protocole herboristerie (usage encadré).
- Inhalation douce : fleurs dans un bol d'eau chaude (non bouillante), tête couverte.
- 🌡️ **Sensibilité à la chaleur** : les composés aromatiques (chamazulène, bisabolol) sont volatils : eau bouillante + absence de couvercle = perte d'actifs.
- Erreurs courantes : faire bouillir les fleurs ; infuser à découvert.

## 4. Posologie
- Adulte : 2–3 tasses/jour, dont une le soir si usage sommeil.
- Enfant : demi-dose après avis professionnel (> 3 ans).
- Durée : usage ponctuel ou cures de 2–3 semaines, pauses entre cures.

## 5. Contre-indications
- Populations : grossesse/allaitement (usage ponctuel toléré, avis professionnel pour usage régulier) ; allergies aux Astéracées.
- Situations pathologiques : antécédents d'allergie pollinique croisée.

## 6. Interactions médicamenteuses
- Prudence théorique avec les anticoagulants (données limitées).

## 7. Signaux d'alerte
- Réaction allergique (démangeaisons, gonflement, gêne respiratoire) → arrêt immédiat et consultation.
- Symptômes digestifs persistants > 5 jours → consulter.

## 8. Note
Plante de jardin facile à cultiver ; fleurs à sécher à l'ombre, sur claies, en local aéré.
