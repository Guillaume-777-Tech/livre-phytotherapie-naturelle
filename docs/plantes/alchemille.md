# Alchémille — *Alchemilla vulgaris* (Rosacées)

**Encadré de sécurité** : prudence en cas de traitement anticoagulant ; usage interne déconseillé pendant la grossesse (effet traditionnel sur le tonus utérin).

## 1. Identité
- Autres noms : manteau de dame, pied-de-lion, herbe aux femmes.
- Parties utilisées : parties aériennes (feuilles et sommités).
- Origine : 🇫🇷 France (sauvage, prairies de montagne — Alpes, Massif central, Vosges).

## 2. Usages
- Traditionnels : « l'herbe des femmes » des montagnes : cycles, abondance menstruelle, suites de couché (usage traditionnel très ancien) ; le nom vient des alchimistes qui recueillaient la rosée de ses feuilles pour leurs travaux.
- Documentés : usage traditionnel reconnu (EMA, *Alchemillae herba*) pour les troubles menstruels légers.

## 3. Préparations
- Infusion : 1–2 g de feuilles / 250 ml — eau 80–90 °C, couvert, 10 min.
- 🌡️ Sensibilité : tanins assez stables ; infusion douce standard, couvercle pour les composés volatils légers.
- Erreurs courantes : s'attendre à un effet immédiat (usage traditionnel en cure, sur plusieurs cycles).

## 4. Posologie
- Adulte (femme) : 1–2 tasses/jour ; usage traditionnel : en deuxième moitié de cycle, sur 2–3 cycles pour évaluer.
- Grossesse : usage interne déconseillé sans avis professionnel (tradition tonifiante utérine).

## 5. Contre-indications
- Grossesse (par prudence, avant terme) ; allaitement : données limitées ; troubles de la coagulation : prudence.

## 6. Interactions
- Anticoagulants (tanins + tradition hémostatique) → espacer, avis professionnel.

## 7. Signaux d'alerte
- Saignements menstruels très abondants, prolongés, ou inhabituels → **consultation gynécologique d'abord** (l'alchémille accompagne, elle ne remplace pas un diagnostic).

## 8. Note
Les alchimistes du XVIᵉ s. voyaient dans ses gouttes de rosée « l'eau céleste » ; les femmes des montagnes y voyaient plus prosaïquement leur tisane de chaque mois.

## 9. Sources
- EMA, *Alchemillae herba* (usage traditionnel). — À compléter (#6).
