# Calendula (souci) — *Calendula officinalis* (Astéracées)

## 1. Identité
- Autres noms : souci officinal, souci des jardins.
- Parties utilisées : fleurs (capitules) ; usage cutané et interne.
- Origine : 🇫🇷 France (cultivée, jardins et producteurs) ; ne pas confondre avec la tagète (« souci d'Inde »).

## 2. Usages
- Traditionnels : peaux irritées, petites blessures, crevasses ; usage cutané remontant au Moyen Âge.
- Documentés : usage traditionnel reconnu (EMA, *Calendulae flos*) pour les petites affections cutanées ; macérat huileux bien documenté.

## 3. Préparations
- **Macérat huileux** (usage cutané principal) : fleurs séchées dans huile d'olive ou tournesol, flacon au soleil ou très doux (< 40 °C) pendant 2–4 semaines ; filtrer soigneusement.
- Infusion : 1 c. à café de fleurs / 250 ml — eau 80–90 °C, couvert, 10 min (usage interne léger).
- Compresse : infusion refroidie appliquée sur la peau.
- 🌡️ Sensibilité : caroténoïdes sensibles à la chaleur — macérat à froid ou très doux uniquement.
- Erreurs courantes : fleurs humides dans l'huile (moisissures) ; confondre calendula et tagète à l'achat.

## 4. Posologie
- Adulte et enfant : application cutanée 1–2×/jour sur peau propre.
- Tisane : 1–2 tasses/jour.
- Durée : usage cutané jusqu'à amélioration ; consulter si pas d'amélioration en 5–7 jours.

## 5. Contre-indications
- Allergie Astéracées ; éviter sur plaies profondes ou infectées (consultation d'abord).

## 6. Interactions
- Prudence avec les traitements hypoglycémiants et sédatifs (données limitées en usage interne).

## 7. Signaux d'alerte
- Rougeur qui s'étend, chaleur, pus → **plaie infectée : consultation médicale**, pas de plante d'abord.

## 8. Note
Le nom vient du latin *calendae* : fleurit presque tous les mois ; l'orange des fleurs colore les salades.

## 9. Sources
- EMA, *Calendulae flos* (usage traditionnel). — À compléter (#6).
