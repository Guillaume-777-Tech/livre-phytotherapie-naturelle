# Cassis — *Ribes nigrum* (Grossulariacées)

## 1. Identité
- Autres noms : groseillier noir, cassis.
- Parties utilisées : feuilles (tisane), baies (alimentation, jus).
- Origine : 🇫🇷 France (Bourgogne, Val de Loire — culture historique du cassis).

## 2. Usages
- Traditionnels : feuilles en tisane « drainante » hivernale et articulaire ; baies contre les fatigues (cassis — le mot date de 1628 à Dijon).
- Documentés : usage traditionnel reconnu (EMA, *Ribis nigri folium*) pour le soutien urinaire léger ; baies riches en anthocyanes et vitamine C.

## 3. Préparations
- Feuilles — infusion : 1 c. à café / 250 ml — eau 90 °C, couvert, 10 min.
- Baies — jus/sirop léger chauffé : **ne jamais dépasser 60 °C** pour préserver la vitamine C.
- 🌡️ Sensibilité : vitamine C détruite au-delà de 60 °C — le sirop de cassis se fait à feu très doux.
- Erreurs courantes : cuire les baies à gros bouillons (vitamine C détruite).

## 4. Posologie
- Adulte : 1–2 tasses de feuilles/jour ; baies cuites doucement à volonté (aliment).
- Enfant : usage alimentaire ; tisane sur avis professionnel.
- Durée : cures de 2–3 semaines.

## 5. Contre-indications
- Grossesse/allaitement : feuilles sur avis professionnel (données limitées) ; maladies rénales : prudence (effet diurétique léger).

## 6. Interactions
- Diurétiques (potentialisation) ; prudence théorique avec les anticoagulants (baies, données limitées).

## 7. Signaux d'alerte
- Symptômes urinaires douloureux, fièvre → consultation (possible infection, pas du ressort d'une tisane).

## 8. Note
Dijon et sa crème de cassis ; la feuille sent le « cassis » caractéristique quand on la froisse.

## 9. Sources
