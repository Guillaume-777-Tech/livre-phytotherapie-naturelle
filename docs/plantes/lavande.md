# Lavande vraie — *Lavandula angustifolia* (Lamiacées)

**Encadré de sécurité** : HE contre-indiquée grossesse, allaitement, enfants < 6 ans, épilepsie (règles générales des HE).

## 1. Identité
- Autres noms : lavande officinale, fine lavande.
- Parties utilisées : fleurs séchées (et HE en aromathérapie encadrée).
- Origine : 🇫🇷 France (Provence — lavande fine de haute altitude, AOP).

## 2. Usages
- Traditionnels : nervosité, sommeil difficile, migraines légères, antiseptique domestique ; usage provençal ancestral.
- Documentés : usage traditionnel reconnu (EMA, *Lavandulae flos*) ; l'HE de lavande est parmi les mieux étudiées.

## 3. Préparations
- Infusion : 1 c. à café de fleurs / 250 ml — eau 80–90 °C, **couvert obligatoire**, 5–8 min.
- 🌡️ Sensibilité : le linalol est **très volatil** : eau frémissante et couvercle non négociables ; jamais d'ébullition.
- Erreurs courantes : infuser à découvert (la senteur qui s'échappe = les actifs qui s'échappent).

## 4. Posologie
- Adulte : 1–2 tasses le soir ; oreiller aromatique (sachet de fleurs séchées).
- Enfant : usage olfactif possible ; tisane après avis professionnel (> 6 ans, très légère).
- Durée : usage ponctuel ou cures courtes.

## 5. Contre-indications
- HE : grossesse, allaitement, < 6 ans, épilepsie ; tisane : prudence chez la femme enceinte en usage régulier.

## 6. Interactions
- HE : prudence avec les sédatifs ; tisane : rien de significatif aux doses habituelles.

## 7. Signaux d'alerte
- Réaction allergique cutanée ou respiratoire → arrêt.

## 8. Note
Distinction à faire entre lavande vraie (fine) et lavandin (plus camphré, moins fin, souvent vendu comme lavande) — vérifier le nom latin à l'achat.

## 9. Sources
- EMA, *Lavandulae flos* (usage traditionnel). — À compléter (#6).
