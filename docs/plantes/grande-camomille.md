# Grande camomille (partenelle) — *Tanacetum parthenium* (Astéracées) 🚩

**⚠️ Encadré de sécurité :**
- Contre-indiquée : grossesse (effet utérotonique), allaitement, enfants < 12 ans, allergie Astéracées.
- **Interactions anticoagulantes documentées** : personne sous AVK/antiagrégant → avis médical impératif.
- Croquer la feuille fraîche peut irriter la muqueuse buccale (aphtes).

## 1. Identité
- Autres noms : matricaire, feuille de Saint-Pierre, partielle, pyrèthre doré.
- Parties utilisées : feuilles (fraîches ou séchées).
- Origine : 🇫🇷 France (sauvage/cultivée, bords de chemins, vieux murs).

## 2. Usages
- Traditionnels : migraines et maux de tête, fièvre du paludisme (« feverfew » anglais) ; utilisée en Grande-Bretagne depuis des siècles.
- Documentés : usage traditionnel reconnu (EMA, *Tanaceti parthenii herba*) pour la prévention des migraines — une des rares plantes avec un usage préventif étudié cliniquement.

## 3. Préparations
- Infusion : 0,5–1 g de feuilles séchées (ou 1–2 feuilles fraîches) / 250 ml — eau 80–90 °C, couvert, 5–8 min. **Goût amer — assumé (c'est l'actif).**
- 🌡️ Sensibilité : parthénolide assez stable ; garder l'infusion douce pour la tolérance.
- Erreurs courantes : s'attendre à un effet immédiat (la partenelle est **préventive** : 4–6 semaines de cure avant d'évaluer) ; croquer les feuilles fraîches tous les jours (aphtes).

## 4. Posologie
- Adulte : 1–2 tasses/jour en cure de 4–6 semaines (usage préventif migraineux).
- Arrêt progressif en fin de cure (arrêt brutal : possible effet rebond de céphalées).

## 5. Contre-indications
- Grossesse, allaitement, enfants ; allergie Astéracées ; troubles de la coagulation.

## 6. Interactions
- Anticoagulants/antiagrégants (interactions documentées) → avis médical impératif.

## 7. Signaux d'alerte
- Aphtes récurrents, réactions allergiques → arrêt ; migraines qui changent de nature ou s'aggravent → consultation neurologique (le diagnostic migraineux appartient au médecin).

## 8. Note
Une plante-médicament au sens propre : usage préventif, délai d'action, effet rebond à l'arrêt — le contre-exemple parfait du « naturel = anodin ».

## 9. Sources
- EMA, *Tanaceti parthenii herba* (usage traditionnel). — Interactions anticoagulantes : à citer (#6).
