# Aubépine — *Crataegus monogyna* (Rosacées)

## 1. Identité
- Autres noms : aubépine monogyne, épine blanche, cenellier.
- Parties utilisées : sommités fleuries (fleurs + quelques feuilles), baies.
- Origine : 🇫🇷 France (sauvage, haies et lisières partout).

## 2. Usages
- Traditionnels : nervosité avec palpitations légères, sommeil agité, « cœurs sensibles » ; usage populaire européen ancien.
- Documentés : usage traditionnel reconnu (EMA, *Crataegi folium cum flore*) pour la nervosité et les palpitations légères d'origine nerveuse.

## 3. Préparations
- Infusion : 1–2 g de sommités / 250 ml — eau 80–90 °C, couvert, 10 min.
- Baies : décoction douce ~95 °C, 10 min (parties plus coriaces).
- 🌡️ Sensibilité : composés volatils floraux → couvert, pas d'ébullition.
- Erreurs courantes : récolter après la floraison (les fleurs fanées sont moins riches).

## 4. Posologie
- Adulte : 2–3 tasses/jour en cure.
- Enfant : usage alimentaire (baies en gelée) ; usage thérapeutique sur avis professionnel.
- Durée : cures de 3–4 semaines.

## 5. Contre-indications
- Grossesse/allaitement : avis professionnel ; pathologies cardiaques : **ne jamais se substituer à un traitement cardiaque**.

## 6. Interactions
- **Prudence renforcée avec les traitements cardiaques (digitaliques, bêta-bloquants)** : avis médical indispensable.

## 7. Signaux d'alerte
- Palpitations inhabituelles, douleur thoracique, essoufflement → **consultation médicale immédiate** (ce n'est pas le rôle d'une tisane).

## 8. Note
Haie emblématique des campagnes françaises ; floraison blanche en mai (« mai » populaire).

## 9. Sources
- EMA, *Crataegi folium cum flore* (usage traditionnel). — À compléter (#6).
