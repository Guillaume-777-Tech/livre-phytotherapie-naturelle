# Houblon — *Humulus lupulus* (Cannabacées)

## 1. Identité
- Autres noms : couleuvrée, vigne du nord.
- Parties utilisées : cônes (fleurs femelles séchées).
- Origine : 🇫🇷 France (Alsace — cultures ; sauvage dans les haies et bord de rivières partout).

## 2. Usages
- Traditionnels : insomnie, nervosité, agitation ; emplâtres de houblon populaires depuis le Moyen Âge ; brassage de la bière.
- Documentés : usage traditionnel reconnu (EMA, *Lupuli flos*) pour le sommeil et la nervosité.

## 3. Préparations
- Infusion : 0,5–1 g de cônes / 250 ml — eau 80–90 °C, couvert, 10 min.
- Erreurs courantes : sous-estimer le volume apparent (les cônes sont très légers — peser, pas « à l'œil »).

## 4. Posologie
- Adulte : 1–2 tasses le soir.
- Enfant : non recommandé.
- Durée : cures de 2–3 semaines.

## 5. Contre-indications
- Grossesse, allaitement, enfants (données insuffisantes) ; prudence si antécédents hormono-dépendants (effet œstrogénique léger documenté).

## 6. Interactions
- Sédatifs (potentialisation) ; prudence théorique avec traitements hormonaux.

## 7. Signaux d'alerte
- Somnolence excessive, réactions cutanées (le houblon frais peut irriter la peau) → arrêt.

## 8. Note
La bière « aide à dormir » par tradition... mais l'alcool dégrade la qualité du sommeil ; la tisane de houblon est l'alliée sérieuse du brasseur.

## 9. Sources
