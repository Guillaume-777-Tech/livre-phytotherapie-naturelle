# Règles illustrations et crédits d'images

> Ticket #5 : Mission illustrations / photographies. Ces règles s'appliquent à TOUTES les images du livre (photos, dessins, planches botaniques, schémas).

## 1. Règle fondamentale : crédit obligatoire sous chaque image

**Toute image insérée dans le livre porte, juste en dessous, une mention de crédit et d'origine.**

- ✅ **Image libre de droits** (domaine public, CC0, CC-BY) :
  > *Crédit : [auteur], licence [CC-BY 4.0 / domaine public], via [source] — vérifié le [date].*
- ✅ **Image réalisée pour le livre** (photographe/illustrateur missionné) :
  > *Crédit : [Nom du photographe/illustrateur], © [année] — réalisation originale pour cet ouvrage.*
- ⚠️ **Image protégée récupérée d'une source externe** (non libre de droits) :
  > *Source : [origine exacte de récupération — site, livre, archive], © [détenteur des droits]. Reproduite avec autorisation. [Référence de l'autorisation écrite]*
  - **AVERTISSEMENT** : une image protégée ne peut être publiée **qu'avec une autorisation écrite du détenteur des droits**. Sans autorisation : l'image est refusée, on la remplace.

## 2. Traduction en légende-type (pour la maquette)

Sous chaque photo/dessin de plante, la légende suit ce modèle :

> **[Nom courant]** — *Nom latin* — [partie représentée]
> Crédit / Source : [selon le cas ci-dessus]

Exemple :
> **Camomille matricaire** — *Matricaria recutita* — fleurs séchées
> Crédit : Jardin des Plantes photographié par L. Martin, © 2026 — réalisation originale pour cet ouvrage.

## 4. Recommandations pour minimiser les images protégées

1. **Priorité aux réalisations originales** : planches botaniques dessinées pour le livre = droits détenus par l'éditeur du projet.
2. **En second recours** : images réellement libres (domaine public — ex. planches anciennes ; CC0 ; CC-BY avec attribution).
3. **En dernier recours uniquement** : image protégée + autorisation écrite.
4. Attention aux pièges : « gratuit » ≠ « libre de droits » ; vérifier la licence au cas par cas, jamais au global.

## 5. Rappel légal (pour le brief graphique, ticket #5)

- Le crédit d'origine sous l'image est une exigence légale (droit d'auteur) et de transparence, cohérente avec la règle des dates (traçabilité des sources — cf. `docs/sites-et-sources-fiables.md`).
- Journaliser chaque source d'image : d'où elle a été récupérée, quand, sous quelle licence.
