# 🌿 livre-phytotherapie-naturelle

Rédaction d'un livre complet et rigoureux sur les soins par les plantes et substances naturelles : phytothérapie, huiles essentielles, tisanes, remèdes traditionnels — toujours avec les précautions d'emploi et un cadre légal clair.

## Structure du dépôt

- `docs/plan-du-livre.md` — plan détaillé et jalons (ticket #1)
- `docs/fiche-type-plante.md` — template de monographie (ticket #2)
- `docs/introduction-avertissement.md` — brouillon introduction + avertissement sanitaire (ticket #4)
- `docs/plantes/` — monographies (à venir, ticket #3)

## Principes de rédaction

1. Le livre **informe, ne remplace pas** un avis médical.
2. Aucune allégation de guérison ; vocabulaire encadré.
3. Chaque fiche cite ses sources ; usage traditionnel signalé comme tel.
4. Contre-indications et interactions systématiques.
